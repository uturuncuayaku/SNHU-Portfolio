# Final project  
Develop and design a Wireframe Mobile App for Kiva borrowers to keep track of their loan status for low bandwidth areas in the world. Used existing SMS infrastructure and simple AndroidOS tools for a wide range of mobile devices to keep track of payments and due dates.

# Nutriscan  
An extra project created to access a food bank API and retrieve results to a mobile application programmed in Java. The mobile application would help a user scan a barcode in the grocery store and get an instant Excellent, Neutral or Bad review of the food. This allows time-concious consumers to quickly assess if the project aligns with their goals and current snack or food inventory.
